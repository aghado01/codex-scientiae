# 5.4.5 Exact evaluation of the Hessian

So far, we have considered various approximation schemes for evaluating the Hessian matrix or its inverse. The Hessian can also be evaluated exactly, for a network of arbitrary feed-forward topology, using extension of the technique of backpropagation used to evaluate ﬁrst derivatives, which shares many of its desirable features including computational efﬁciency (Bishop, 1991; Bishop, 1992). It can be applied to any differentiable error function that can be expressed as a function of the network outputs and to networks having arbitrary differentiable activation functions. The number of computational steps needed to evaluate the Hessian scales like O ( W 2 ) . Similar algorithms have also been considered by Buntine and Weigend (1993).

Here we consider the speciﬁc case of a network having two layers of weights, for which the required equations are easily derived. We shall use indices i and i to denote inputs, indices j and j to denoted hidden units, and indices k and k to denote outputs. We ﬁrst deﬁne

$$
\delta _ { k } = \frac { \partial E _ { n } } { \partial a _ { k } } , \quad M _ { k k ^ { \prime } } \equiv \frac { \partial ^ { 2 } E _ { n } } { \partial a _ { k } \partial a _ { k ^ { \prime } } }
$$

where E n is the contribution to the error from data point n . The Hessian matrix for this network can then be considered in three separate blocks as follows.
