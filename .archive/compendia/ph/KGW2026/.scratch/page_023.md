# 3.2 The First Mayer Path Homology Group H N,q 1

Computation of standard path homology in degree 1 is discussed in [3] by Dey et al. It is shown that when N = 2, the kernel of the boundary map ∂ 1 : Ω 2 1 → Ω 2 0 is generated by cycles in the underlying undirected graph of a given digraph.

More precisely, if G u denotes the underlying undirected graph of G , then a basis of the 1-cycle space can be obtained from a spanning tree of G u . Each non-tree edge determines a unique undirected cycle, and these cycles generate ker( ∂ 1 ) via symmetric difference in mod 2 when coefficients are taken in from any field K .

The following example demonstrates that this phenomenon does not extend to higher roots of unity. In particular, when N ≥ 3, not every undirected cycle lies in the kernel of ∂ 1 : Ω N 1 → Ω N 0 .

$$

$$
v _ { j } = \begin{cases} e _ { i _ { j } , i _ { j + 1 } } , & \text {if } i _ { j } \to i _ { j + 1 } \text { is an edge of } G , \\ e _ { i _ { j + 1 } , i _ { j } } , & \text {otherwise.} \end{cases}
