Corollary A.3. Assume the setting above. If \( A^{\parallel} = 0 = B^{\parallel} \) (resp. \( {=}A = 0 = {=}B \)), then the extramural \( A_{\Box} \stackrel{c}{\longrightarrow} \Box B \) is an isomorphism. \(\Box\)
