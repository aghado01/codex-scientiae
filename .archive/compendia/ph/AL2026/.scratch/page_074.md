Remark 6.8. The above \( \zeta \) does not essentially cover the interval \( I \in \mathcal{I}_l \). To interpret this, let us take \( I = [ \hat{0} , 1 ] \) as an example. By (6.92) we may take

$$
g \coloneqq \begin{bmatrix} p _ { 2 , \hat { 0 } } \\ p _ { 1 ^ { \prime } , \hat { 0 } } \\ p _ { 1 , \hat { 0 } } \end{bmatrix} ,
$$

and by the definition of \( \zeta \), \( \zeta ( p_{2,0} ) = p_{2,\hat{0}} \), \( \zeta ( p_{1^{\prime},\hat{0}} ) = p_{1^{\prime},\hat{0}} \), \( \zeta ( p_{1,0} ) = p_{1,\hat{0}} \). However, we notice the reader that the family

$$
\begin{pmatrix} p _ { 2 , \bar { 0 } } \\ \frac { p _ { 1 ^ { \prime } , \hat { 0 } } } { p _ { 1 , \bar { 0 } } } \\ \end{pmatrix}
$$

does not satisfy the matrix condition, and cannot be a morphism in \( k[Z] \), and hence \( \zeta \) does not essentially cover \( I = [ \hat{0} , 1 ] \).
