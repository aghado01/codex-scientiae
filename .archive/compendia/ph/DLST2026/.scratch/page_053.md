[Page 53]

We have two choices of AR-cascades to make the filtration basic:

\[
\begin{aligned}
\mathcal { B } _ { 1 ^ { \prime } } & \coloneqq \{ B _ { \beta , 1 ^ { \prime } } \coloneqq \{ b , b c \} , B _ { \gamma , 1 ^ { \prime } } \coloneqq \{ c \} \} \quad \text {or} \\ \mathcal { B } _ { 1 ^ { \prime } } & \coloneqq \{ B _ { \beta , 1 ^ { \prime } } \coloneqq \{ b \} , B _ { \gamma , 1 ^ { \prime } } \coloneqq \{ c , b c \} \} .
\end{aligned}
\]

As shown in Figure 26 , the 0-degree generator corresponding to B • , 0 continues to B β, 1 in the first case, while in the second, it continues to B γ, 1 . Nevertheless, the barcodes are isomorphic in terms of persistence.

This ambiguity is not merely combinatorial. Note that in the continuous pitchfork bifurcation (Figure 27 left) none of the newly created attractors inherits the generator either: the attractor at λ = 0 continues to the invariant interval consisting of all equilibria and trajectories connecting them. However, if we perturb the system (Figure 27 right), we obtain uniqueness, and such a perturbation precisely corresponds to the choice of an AR-cascade.

- Extension to other settings: There is a natural question of extending the construction to other settings, for example, parameterized continuous flows, or discrete-time dynamical systems.
- Improvement of the algorithm: Currently we employ the incremental algorithm described in [ 21 ] to compute the Conley-Morse persistence barcode. Can the fast zigzag algorithm presented in [ 16 ] be adapted to this setting to make the computation more practical?
