3.3. Relations. Let R ⊂ X × X be a binary relation on a set X . A pair ( X,R ) is called a partially ordered set (or a poset ) if R is a reflexive, antisymmetric, and transitive relation. If additionally any two elements of X are comparable then ( X,R ) is called a linear order . A linear order ( X,R ′ ) is a linear extension of a partial order ( X,R ) if R ⊂ R ′ .

For a partial order ( X, ≤ ) and x,y ∈ X we write x ≺ y if there is no z ∈ X \ { x,y } such that x < z < y . The Hasse diagram of a partial order ( X, ≤ ) is a restriction of ≤ to pairs ( x,y ) such that x ≺ y .

A subset A ⊂ X is called an upper set if x < y and x ∈ A implies y ∈ A . Symmetrically, A is a down set if x < y and y ∈ A implies x ∈ A . An intersection of a down set and an upper set is called a convex set .
