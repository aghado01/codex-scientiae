The diagram in Figure 2 presents the so-called Conley–Morse persistence barcode capturing the evolution of the vector field on the sphere in terms of Conley indices. Prior to explaining the diagram, we recall a few standard definitions.

Given a vector field φ , an invariant part of a set S ⊂ R n is Inv S : = { x ∈ S | φ ( R ,x ) ⊂ S } . In particular, S is invariant if Inv S = S . We say that a set is an isolated invariant set if there exists a compact neighborhood N of S such that S = Inv N ⊂ int N . The equilibria and the periodic orbit in our example are instances of isolated invariant sets.
