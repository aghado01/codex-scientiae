The following two theorems relate the diagrams of f and − f if the domain X is a manifold [7]. Denoting with superscript T the reflection across the principal diagonal, ( x, y )  → ( y, x ), we get the following duality.

EP Duality Theorem [7] . The persistence diagrams of a real-valued function f on a d -manifold are reflections of each other, Dgm r ( f ) = Dgm T d − r ( f ).

Denoting with the superscript R the reflection across the minor diagonal, ( x, y )  → ( − y, − x ), with the superscript 0 the composition of reflections T and R , i.e. the central reflection through the origin, ( x, y )  → ( − x, − y ), and by Ord , Ext, and Rel, the ordinary, extended, and relative subdiagrams, the authors state the following symmetry.

EP Symmetry Theorem [7] . Given a real-valued function f on a d -manifold, its persistence subdiagrams are related by

$$
$$
\begin{array} { r l r } { O r d _ { r } ( f ) } & { = } & { O r d _ { d - r - 1 } ^ { R } ( - f ) , } \\ { E x t _ { r } ( f ) } & { = } & { E x t _ { d - r } ^ { 0 } ( - f ) , } \\ { R e l _ { r } ( f ) } & { = } & { R e l _ { d - r + 1 } ^ { R } ( - f ) . } \end{array}
$$
$$
