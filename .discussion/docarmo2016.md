## The thesis

Don't scale. **Take one worthy document to a deliverable you're satisfied with**, and let that single run
be the forcing function that wakes everything that's gone dormant:

- It exercises the work-order / hotspot / span machinery **at book scale** for the first time (the 3
  finalized items are ~30-page papers; this is a textbook).
- It generates the **real chunk stream** that the two data-dependent loose ends (#7 gibberish
  recalibration; governance fire-rate) have been waiting on.
- It produces a finished artifact — the morale fix the plateau actually needs.

The run is **depth-1, no swarm.** Per PROCEDURE.md: *"A single document with no swarm is the same loop at
depth 1: you are the worker."* No sub-agent dispatch, no `dispatch` fan-out — just the per-unit repair loop,
worked by hand, the seeing agent and the working agent collapsed into one. (This also honours the standing
no-sub-agent constraint.)
