Figure 3.5 Illustration of the dependence of bias and variance on model complexity, governed by a regularization parameter λ, using the sinusoidal data set from Chapter 1. There are L = 100 data sets, each having N = 25 data points, and there are 24 Gaussian basis functions in the model so that the total number of parameters is M = 25 including the bias parameter. The left column shows the result of ﬁtting the model to the data sets for various values of ln λ (for clarity, only 20 of the 100 ﬁts are shown). The right column shows the corresponding average of the 100 ﬁts (red) along with the sinusoidal function from which the data sets were generated (green).
