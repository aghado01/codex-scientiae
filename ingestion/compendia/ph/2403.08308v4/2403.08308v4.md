# Appendix A Original definition of a compression system

To deal with not only incidence categories of posets but also linear categories A defined by bound quivers ( Q,R ) as A = k [ Q ] /R , the original definition of a compression system was described in a quiver language, which is recorded below for the future use. To begin with, we summarize some fundamental but necessary notations for the paper to be self-contained. For a thorough treatment, we refer the reader to [ 19 ].

Definition A.1. (1) A quiver is a quadruple Q = ( Q 0 ,Q 1 ,s,t ) of sets Q 0 ,Q 1 and maps s,t : Q 1 → Q 0 . If we draw each x ∈ Q 0 as a vertex, and each α ∈ Q 1 with s ( α ) = x and t ( α ) = y as an arrow x α −−→ y , then Q can be expressed as a directed graph. For this, elements of Q 1 are said to be the arrows of Q , and s ( α ) ,t ( α ) are said to be the source and target of the arrow α .

- (2) Let Q,Q ′ be quivers. A quiver morphism F from Q to Q ′ is a pair ( F 0 ,F 1 ) of maps F i : Q i → Q ′ i ( i = 0 , 1 ) such that for any arrow a : x → y , in Q , F 1 ( a ) is an arrow F 0 ( x ) → F 0 ( y ) . By abuse of notation, we write F ( a ) = F 1 ( a ) ,F ( x ) := F 0 ( x ) for all a ∈ Q 1 , x ∈ Q 0 .
- (3) A path from x to y of length n ≥ 0 is a symbol p = ( y | α n ,...,α 1 | x ) consisting of α 1 ,...,α n ∈ Q 1 such that y = t ( α n ) , x = s ( α 1 ) and s ( α i +1 ) = t ( α i ) for i ∈ [ n − 1] . If n = 0 , we require x = y and set e x : = ( x || x ) . The symbol p is sometimes expressed by p : x ⇝ y . To extend definitions of source and target to paths, we set s ( p ) : = x, t ( p ) : = y and call them the source and target of p .

Remark A.5. Let ACQ be the category of all acyclic finite quivers without multiple arrows, where the morphisms are given by quiver morphisms, and FP the category of all finite posets and order-preserving maps. If Q ∈ ACQ , then we have a finite poset O ( Q ) := ( Q 0 , ⪯ ) ∈ FP , where x ⪯ y if and only if there exists a path x ⇝ y for all x,y ∈ Q 0 . Conversely, if P ∈ FP , then H ( P ) ∈ ACQ . These induce isomorphisms O : ACQ → FP and H : FP → ACQ of categories, which are inverses to each other.

We usually identify ACQ and FP by these isomorphisms. Note that if Q = H ( P ) for a P ∈ FP 0 , then k [ P ] ∼ = k [ Q ] / com Q .

Remark A.6. Let I be a full subposet of P , set Q := H ( P ) , and let Q ′ be the full subquiver of Q with Q ′ 0 = I . Then clearly I is convex in P if and only if Q ′ is convex in Q . For connectedness, consider the following conditions:

- (1) I is connected as a poset.
- (2) The Hasse quiver H ( I ) of I is connected as a quiver.
- (3) Q ′ is connected as a quiver.


Then (1) and (2) are equivalent because for any x,y ∈ I , we have x ≤ y if and only if there exists a path x ⇝ y in H ( I ) by definition of a Hasse quiver.

Moreover, (3) implies (1) because for any x,y ∈ I , if there exists a path x ⇝ y in Q ′ , then x ≤ y in I .

However, (1) does not imply (3). For example, consider the case, where P = { 1 < 2 < 3 } and I := { 1 , 3 } . In this case, Q = (1 → 2 → 3) , H ( I ) = (1 → 3) and Q ′ = (1 3) . Thus I is connected, but Q ′ is not connected.

Nevertheless, if I is convex in P (or equivalently Q ′ is convex in Q ), then (1) implies (3), and all the conditions above are equivalent. Indeed, if x ≤ y in I , then there exists a path p : x ⇝ y in Q , with x,y ∈ Q ′ , then p is a path in Q ′ because Q ′ is convex in Q .

Therefore, I is an interval of P if and only if Q ′ is an interval of Q .
