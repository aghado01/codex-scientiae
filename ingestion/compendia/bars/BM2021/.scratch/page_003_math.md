In   this   context,   it   should   be   mentioned   that   in   many   applications   categorical   variables   may   arise.   The   problem   on   how   to   deal   with   discrete   variables   in   fully   nonparametric   regression   problems   has   been   considered   in   the   statistical   literature,   by   several   authors.   Among   others,   we   can   mention   the   proposals   based   on   splines   for   the   continuous   covariates   and   on   discrete-support   kernel   functions   for   the   categorical   ones,   considered   in   Racine   and   Li   ( 2004 ) and   Ma   et   al.   ( 2015 ) for   nonparametric   regression   models   and   by   Ma   and   Racine   ( 2013 ) for   additive   models.   As   mentioned   in   Camlong-Viot   et   al.   ( 2006 ),   who   considered   a   kernel   approach   combined   with   marginal   integration,   in   the   econometric   literature   categorical   covariates   are   usually   included   in   the   form   of   linear   parametric   functions,   see   also   Ma   and   Yang   ( 2011 ).   Throughout   this   paper,   as   in   Ma   and   Yang   ( 2011 ) who   considered   a   least   squares   approach   or   Guo   et   al.   ( 2013 ) and   Sherwood   and   Wang   ( 2016 ) whose   proposal   is   based   on   quantile   regression,   we   will   assume   that   discrete   variables   if   present   are   included   in   the   model   as   some   of   the   components   of   the   vector   Z whose   relation   with   the   responses   is   modeled parametrically.

The   rest   of   the   paper   is   organized   as   follows.   In   Section 2,   we   describe   our   robust   proposal,   while   theoretical   results   regarding   consistency   and   rates   of   convergence   are   presented   in   Section 3.  Furthermore,   asymptotic   normality   is   established   for   the   estimators   of   β in   Section 4.  The   results   of   a   numerical   study   conducted   to   compare   the   ﬁnite-sample   properties   of   the   classical   least   squares   and   the   robust   MM -estimator   are   summarized   in   Section 5,   while   Section 6 contains   the   analysis   of   the   Boston   housing   data   set.   Some   ﬁnal   comments   are   presented   in   Section 7.  All   proofs   are   relegated   to   the   Appendix   or   to   the   supplementary   ﬁle   available   on-line,   where   some   additional   numerical   results   are   also   included.

As   mentioned   in   the   introduction,   we   will   consider   i.i.d.   observations   ( Y i,   Z t i,   X t i ) t satisfying   the   partially   linear   additive   model   ( 2 ) where   X i has   support   on     p j = 1 I j.  From   now   on,   given   two   random   vectors   W   ∈ R s and   V   ∈ R s,   we   denote   W   ∼ V whenever   W and   V have   the   same   distribution.   In   the   sequel,   ( Y,   Z t,   X t ) t stands   for   a   random   vector   with   the   same   distribution   as   ( Y 1,   Z t 1,   X t 1 ) t,   that   is,   ( Y,   Z t,   X t ) t ∼ ( Y 1,   Z t 1,   X t 1 ) t.  To   ensure   identiﬁability   of   the   additive   components   η j : I j → R,   we   will   impose   the   constraint     I j η j ( x )   dx   = 0,   for   j   = 1,   ...,   p.  The   errors   ε are   assumed   to   be   independent   of   the   explanatory   variables   ( Z t,   X t ) t.  Taking   into   account   that   we   intend   to   deﬁne   robust   estimators,   we   avoid   moment   conditions   for   the   error’s   distribution   by   only   assuming   that   their   distribution   F ( · ) is   symmetric   with   scale   parameter   1. Our   robust   proposal   combines   B -splines   with   regression   MM -estimators,   that   is,   the   estimators   to   be   deﬁned   in   Sec-

tion 2.2 are   based   on   MM -regression   estimators   after   approximating   each   component   η j by   a   spline   as   described   in   Section 2.1.  Under   a   linear   regression   model,   MM -estimators   were   introduced   in   Yohai   ( 1987 ).   A   detailed   description,   as   well   as   an   algorithm   allowing   to   compute   them,   can   be   seen   in   Maronna   et   al.   ( 2019 ).   As   it   is   well   known,   to   attain   robustness   and   eﬃciency,   MM -estimators   are   deﬁned   through   a   two–step   procedure.   In   the   ﬁrst   step,   a   preliminary   robust   regression   estimator   is   used   to   estimate   the   scale   parameter.   This   initial   estimator   may   be   ineﬃcient   but   should   have   a   high   breakdown   point.   In   the   second   step,   an   M -estimator   is   computed   using   a   bounded   loss   function   applied   to   the   standardized   residuals.   In   this   way,   the   ﬁnal   estimator   will   retain   the   high   breakdown   point   of   the   initial   one   but   its   eﬃciency   will   be   improved   by   the   use   of   an   appropriate   loss   function   in   the   second   step.   The   next   two   sections   contain   the   details   of   our   proposal.

To   approximate   each   additive   function   η j in   ( 2 ) by   a   spline,   ﬁx   the   desired   spline   order     j,   the   number   of   interior   knots   N n, j and   their   location   T j.  As   it   is   well   known,   the   class   of   splines   of   order     j > 1 with   knots   T j is   spanned   by   a   B -spline   basis   functions   with   dimension   k j = k n, j = N n, j +   j,   see   Corollary   4.10   of   Schumaker   ( 1981 ).   We   will   denote   this   basis   {   B ( j ) s : 1   ≤ s   ≤ k n, j }.  It   is   worth   mentioning   that   a   spline   of   order     is   a   polynomial   of   degree       − 1 within   each   subinterval.
