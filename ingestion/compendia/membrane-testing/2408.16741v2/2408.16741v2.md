# The persistent Laplacian of non-branching complexes

Magnus Bakke Botnan 1 and Rui Dong 1

1 Department of Mathematics, Vrije Universiteit Amsterdam, The Netherlands

# Abstract

Non-branching matrices are real matrices with entries in {− 1 , 0 , 1 } , where each row contains at most two non-zero entries. Such matrices naturally arise in the study of Laplacians of pseudomanifolds and cubical complexes. We show that a basis for the kernel of a non-branching matrix can be computed in near-linear time. Especially, the basis has the special property that the supports of all the column vectors in it are disjoint with each other. Building on this result, we show that the up persistent Laplacian can be computed in near-linear time for a pair of such spaces and its eigenvalues can be more efficiently computed via computing singular values. In addition to that, we analyze the arithmetic operations of up persistent Laplacian with respect to a non-branching filtration. Furthermore, we show that the up persistent Laplacian of q -non-branching simplicial complexes can be represented as the Laplacian of an associated hypergraph, thus providing a higher-dimensional generalization of the Kron reduction, as well as a Cheeger-type inequality. Finally, we highlight the efficiency of our method on image data.

# 1 Introduction

The eigenvectors and eigenvalues of the Laplacian for graphs carry important structural information about the underlying graph and have found numerous applications throughout the sciences [ VL07 , Lim20 ]. Recently, extending these ideas to (filtrations) of simplicial complexes and hypergraphs have become an active topic of research with significant potential. In this paper, our focus lies with the persistent Laplacian [ WNW20 , MWW22 , GMWW23 ], which is a generalization of the classical Laplacian to pairs of spaces. Specifically, for a pair of simplicial, or cubical, complexes K   → L , the q -th persistent Laplacian △ K , L q is defined as the sum of the up persistent Laplacian △ K , L q, up and the standard down Laplacian △ K q, down on K . It is worth remarking that this allows for a generalized version of the celebrated Hodge theorem [ MWW22 ]: the nullity of △ K , L q is equal to the q -th persistent Betti number of the pair K   → L . Additionally, the spectra of △ K , L q encode finer geometric information of a dataset, which cannot be extracted via standard TDA techniques such as persistent homology [ DWSG23 , WW23 ]. ,

The bottleneck in computing the persistent Laplacian is the computation of △ K L q, up , for which two algorithms were recently proposed in [ MWW22 ], both with cubic time complexity. Specifically, if the number of q -simplices and ( q + 1)-simplices of L are denoted by n L q and n L q +1 , respectively, the time complexity of computing the up persistent Laplacian △ K , L q, up is

$$
O \left ( n _ { q } ^ { \mathcal { L } } ( n _ { q + 1 } ^ { \mathcal { L } } ) ^ { 2 } + ( n _ { q + 1 } ^ { \mathcal { L } } ) ^ { 3 } \right ) \quad \text {or} \quad O \left ( ( n _ { q } ^ { \mathcal { L } } ) ^ { 3 } \right ) ,
$$

depending on whether Gaussian elimination or the Moore–Penrose pseudoinverse of a matrix is used. For further details, see [ MWW22 , Algorithm 3.1, Algorithm 4.1], and for a recent survey of persistent Laplacians, we refer to [ WW23 ].

# 2 Column reduction of non-branching matrices

In this section, we prove the following central theorem for non-branching matrices , i.e., real matrices with elements in {− 1 , 0 , 1 } and for which every row contains at most two non-zero entries. For a vector v , we refer to the non-zero values as support values of v , and the corresponding indices as support indices of v .

Theorem 2.1. Let D be a non-branching matrix without zero columns. Then, one can find matrices R ∈ M k × l ( R ) and V ∈ M l × l ( R ) such that R = DV , where V is upper-triangular with entries in {− 1 , 0 , 1 } , the non-zero columns of R are linearly independent, and the support indices of columns in V are mutually disjoint. Furthermore, the i -th column of V has more than one non-zero entry if and only if the i -th column of R is zero.

We refer to such a matrix factorization as a weak column reduction of D . The matrix R is not column reduced in the sense of the “standard algorithm” [ EH10 , Ch. VII.1] as multiple columns may have their pivots (lowest non-zero entry) at the same row. Note that the columns of V with more than one non-zero entry constitute an orthogonal basis for the kernel of D .

It will be useful to decompose a non-branching matrix D into its orientable and non-orientable components. The following definition is inspired by the structure of the k -th boundary map of an oriented k -pseudomanifold.

Remark 2.2. In this section, we focus on matrices with real-valued entries. However, Theorem 2.1 extends verbatim to arbitrary unital rings that admit constant-time arithmetic operations. In fact, for rings of characteristic 2, the arguments simplify, as every non-branching matrix can be considered oriented.

# 2.2 Regular matrices

In this subsection, D is assumed to be a regular matrix (Definition 2.5 ). Without loss of generality, we shall assume that D has a non-zero entry in every column and every row. In particular, since every column contains precisely two non-zero entries with opposite signs, its transpose D T is the incidence matrix of a directed graph G . The following fundamental result from algebraic graph theory will be important; see e.g. [ GR01 , Theorem 8.3.1] for a proof.

# 2.4 Row-singular matrices

If D ∈ M k × l ( R ) is row-singular, we can interpret ( | D | ) T as the incidence matrix of an undirected graph with loops, recall that | D | = ( | d ij | ) for D = ( d ij ).

Lemma 2.15. Let D ∈ M k × l ( R ) be a row-singular matrix without zero-columns and zero-rows. Let G be the undirected graph with loops whose incidence matrix is equal to | D | T . The matrix D has full column rank if the associated graph G has only one connected component.

Proof. To prove that D has full column rank, it is enough to prove that Dv = 0 if and only if v = ( v 1 , ··· ,v l ) ∈ R l is the zero vector. Since the undirected graph G is connected by assumption, we obtain that | v 1 | = ··· = | v l | as in the proof of Lemma 2.13 . However, since D is row-singular, there must be some row containing only one non-zero entry, and thus v j = 0 for some j . It follows that v = ( v 1 , ··· ,v l ) = 0.

Remark 2.16. When D is row-singular, each edge in G contains either one or two vertices. we see that the loops in G will not be relevant in the computation of connected components. Therefore, we can ignore the loops, and find the connected components of G by running any algorithm for computing connected components in graphs.

# 2.6 Algorithms and running times

In this section we analyze the time complexity of computing weak column reduction. Since a nonbranching matrix D is sparse, we assume that the input matrix D is in a format of sparse matrix. There are several different options, such as Compressed Sparse Column (CSC), Compressed Sparse Row (CSR), and Coordinate (COO).

The key algorithm in computing weak column reduction with respect to a k × l non-branching matrix D is to find connected components, with input being an incidence matrix. There are multiple algorithms that can achieve this, such as depth-first-search (DFS), Breadth-First Search (BFS), and Union-Find (Disjoint Set Union, DSU). We refer to [ CLRS22 ] for more details about graph algorithms. In this work we apply DSU based on the following reasons: Firstly, our input data is an incidence matrix with respect to a graph, by applying DFS or BFS one has to first convert an incidence matrix to adjacency lists, which will take O ( kl ), while DSU has near-linear time O ( k α ( l )), here α ( l ) is the inverse Ackermann function, an extremely slow-growing function. 2 Secondly, DSU excels for dynamic graphs, i.e., edges and loops varies, this happens when computing boundary matrices with respect to a non-branching simplicial filtration. This will become important in Section 3.3 .

Suppose the input D ∈ M k × l ( R ) is a non-branching sparse (CSR format) matrix. Recall that | D | is the matrix whose non-zero entries are the absolute values of those in D . It is easy to see that the computation of | D | from D takes O ( k ). We consider | D | as the transpose of an incidence matrix with respect to an undirected graph with loops, that is, we regard each column in | D | as a vertex, and each row as an edge or a loop. We first apply DSU (see Algorithm 4 in Appendix B ) to find all components, which takes O ( kα ( l )), recall that in DSU algorithm, two operations Union (see Algorithm 5 in Appendix B ) and Find (see Algorithm 6 in Appendix B ) are used to merge two sets and find the root of a component, respectively, and the components are stored in the list “parent” that contains the root of each vertex. We then need to find the vertices having self-loops and their corresponding roots, when | D | is stored in the CSR format, it takes O ( k ). 3 Next we need to filter out these roots, which takes O ( k + l ) if we traverse the list of parents once and use a hash map to track indices for all roots.

We then need to reorient a non-branching matrix so that filter out all the irregular components. The main idea is to check if we can ensure that each entry in the column sum is not equal to 2 and − 2 by flipping the column signs of D . If this is impossible, then the matrix D is non-orientable. We initialize the flag list to be l copies of 1s, and scan over rows of D , if the column sum is 2 or − 2, we flip the flag list. The Reorientation algorithm is shown in Algorithm 1 . Since D is stored in CSR format, finding the column indices of non-zero entries in each row takes O (1), hence the time complexity of Reorientation is O ( k ).

We summarize the time complexity analysis in the following proposition.

Proposition 2.18. Let D ∈ M k × l ( R ) non-branching matrix. The time complexity of weak column reduction Algorithm 2 is O ( k × α ( l ) + l ).

Proof. Recall that DSU takes O ( k × α ( l )), and the procedure of searching roots with respect to loops takes O ( l ) since the size of vertices is l . Retrieving the column partition { I r } r and the corresponding row partition { J r } r takes O ( l ) and O ( k ), respectively, computing Reorientation ( D r ) takes O ( | J r | ), and updating E ( I r ,I r ) takes O ( I r ), therefore, it takes O ( k × α ( l ) + l ).

# 4 A generalized Kron reduction and a Cheeger inequality

In graph theory, the eigenvalues of the graph Laplacian (specifically, the up Laplacian) encode crucial information about connectivity, clustering, and expansion. For instance, the smallest non-zero eigenvalue reflects how well-connected the graph is, as captured by the Cheeger inequalities. Recently, a Cheeger-type inequality for the Hodge Laplacian on simplicial complexes was established in [ JZ23 ], and a Cheeger inequality for the persistent graph Laplacian was given in [ MWW22 ]. However, as noted in [ WW23 ], very little is known about the topological interpretation of the eigenvalues and eigenvectors of persistent Laplacians. In this section, we show that the setting of non-branching complexes provides a clearer understanding of the eigenvalues of the up persistent Laplacian. ,

Concretely, in Section 4.1 , we show that ∆ K L q, up coincides with the Laplacian of a weighted oriented hypergraph, under the assumption that L is unweighted and q -non-branching. The relevant theory for hypergraphs is provided in Appendix C . This type of reduction—where the persistent (graph) Laplacian is replaced by the Laplacian of a single graph—is known as a Kron reduction . However, as shown in [ MWW22 , Section SM5], one cannot, in general, replace the up persistent Laplacian of a pair of simplicial complexes with the Laplacian of a single simplicial complex. Exploring generalizations of Kron reduction to the simplicial setting is therefore left by the authors as an open direction for future work. Our result thus provides a partial answer to this open problem.

Leveraging the connection to hypergraphs, we establish a Cheeger-type inequality for the smallest non-zero eigenvalue in Section 4.2 . To the best of our knowledge, this is the first result of its kind for the up persistent Laplacian of simplicial complexes.

Remark 4.1. While we do not make the statements explicit, all of the following results apply verbatim to the case of cubical complexes.

# 5 Computing eigenvalues

As mentioned in Section 4 , the eigenvalues of graph and Hodge Laplacians carry important topological and geometrical information. However, there are two drawbacks of computing the eigenvalues of the up persistent Laplacian ∆ K , L q, up directly. First, it is computationally intensive. The construction of this matrix requires a quadratic number of operations in the number of simplices (Proposition 3.10 ), and computing its full eigenvalue spectrum generally requires O   ( n K q ) 3   operations. Furthermore, for moderately sized complexes, ∆ K , L q, up can become unmanageably large and dense, rendering a spectral theory approach impractical for many applications. Second, the up persistent Laplacian ∆ K , L q, up relies on the weight matrices W L , K q +1 and W K q , in practical application, when the entries in W L , K q +1 and ( W K q ) − 1 are close to the machine epsilon 4 for the device being used, it may lead to erroneous results to compute eigenvalues directly from the up persistent Laplacian ∆ K , L q, up . The readers can consult Appendix F for a concrete example.

After k iterations, this procedure generates a k × k bidiagonal matrix whose singular values approximate k singular values of M . Which k singular values the algorithm approximates depends on the choice of starting vector and the distribution of singular values, but generically the largest singular value will be well-approximated. Importantly, the convergence rate of the GKL algorithm is not uniform across the spectrum; convergence to the largest singular values is much quicker, and they can thus be approximated with high accuracy using relatively few iterations. For a detailed treatment of the GKL algorithm, we refer the reader to [ GVL13 , BDD + 00 ] and Appendix E . We summarize the relevant results below.

Proposition 5.1. Let K   → L be a pair of simplicial complexes as described in Theorem 3.8 . By iterating k steps, the GKL algorithm computes approximations to k eigenvalues of ∆ K , L q, up in

$$
O \left ( ( n _ { q } ^ { \mathcal { L } } - n _ { q } ^ { \mathcal { K } } ) \times \alpha ( n _ { q + 1 } ^ { \mathcal { L } } ) + k \times ( n _ { q + 1 } ^ { \mathcal { L } } + n _ { q } ^ { \mathcal { K } } ) + k ^ { 2 } \right ) .
$$

Proof. The total complexity arises from three main steps. First, the cost of constructing the necessary components of the matrix M is given by ( n L q − n K q ) × α ( n L q +1 ), as established in Proposition 3.10 . Second, the cost of computing a k × k bidiagonal matrix using GKL algorithm is bounded by O ( k × ( n L q +1 + n K q )) (see Proposition E.1 ). Finally, according to [ BDD + 00 , Section 6.2], it costs O ( k 2 ) to compute the eigenvalues of a k × k bidiagonal matrix. Hence the result follows.

From Corollary 3.16 , this result directly carries over to a simplex-wise filtration.

Corollary 5.2. Let K 0   → K 1   → ···   → K m   → L be a q -non-branching simplicial filtration where each K i contains exactly one more q -simplex than K i − 1 for each 1 ≤ i ≤ m . The GKL algorithm computes approximations to k eigenvalues of the matrices in { ∆ K i , L q, up } m i =0 in

$$
O \left ( n _ { q } ^ { \mathcal { L } } \times \left ( ( k + 1 ) \times ( n _ { q + 1 } ^ { \mathcal { L } } + n _ { q } ^ { \mathcal { L } } ) + k ^ { 2 } \right ) \right )
$$

arithmetic operations. In particular, the corresponding computation for all the matrices { ∆ K i , K j q, up } i ≤ j can be done in 2 2

$$
O \left ( ( n _ { q } ^ { \mathcal { L } } ) ^ { 2 } \times \left ( ( k + 1 ) \times ( n _ { q + 1 } ^ { \mathcal { L } } + n _ { q } ^ { \mathcal { L } } ) + k ^ { 2 } \right ) \right )
$$

arithmetic operations.

Proof. The result is obtained by computing all the matrices following Proposition 5.1 and then applying Corollary 3.16 to each matrix individually using the worst case where n L q − n K m q + m = n L q in the first expression and ( m +1)( n L q +1 + n K m q ) = n L q ( n L q +1 + n L q ) in the second expression, and m +1 = n L q . This thus gives a computational time of

$$
O \left ( n _ { q } ^ { \mathcal { L } } \times \left ( \alpha ( n _ { q + 1 } ^ { \mathcal { L } } ) + n _ { q + 1 } ^ { \mathcal { L } } + n _ { q } ^ { \mathcal { L } } \right ) \right ) .
$$

There are O ( n L q ) matrices, and so the cost of computing the k eigenvalues from Proposition 5.1 becomes

$$
O \left ( n _ { q } ^ { \mathcal { L } } \times \left ( \alpha ( n _ { q + 1 } ^ { \mathcal { L } } ) + n _ { q + 1 } ^ { \mathcal { L } } + n _ { q } ^ { \mathcal { L } } + k \times ( n _ { q } ^ { \mathcal { L } } + n _ { q + 1 } ^ { \mathcal { L } } ) + k ^ { 2 } \right ) \right ) .
$$

Adding these worst-case complexities together gives the desired result. The final bound is obtained by multiplication with the length of the filtration, which is at most n L q .

It is well known [ HJ13a , Section 2] that the non-zero eigenvalues of the persistent Laplacian

$$
\Delta _ { q } ^ { \mathcal { K } , \mathcal { L } } = \Delta _ { q , u p } ^ { \mathcal { K } , \mathcal { L } } + \Delta _ { q , d o w n } ^ { \mathcal { K } }
$$

are given by the union (counted with multiplicity) of the eigenvalues of the up Laplacian and the down Laplacians. This is immediate from

$$
\Delta _ { q , u p } ^ { \mathcal { K } , \mathcal { L } } \circ \Delta _ { q , d o w n } ^ { \mathcal { K } } = \Delta _ { q , d o w n } ^ { \mathcal { K } } \circ \Delta _ { q , u p } ^ { \mathcal { K } , \mathcal { L } } = 0 .
$$

Since the multiplicity of the 0 eigenvalue in ∆ K , L q equals the q -th persistent Betti number of the inclusion K   → L , information already captured by persistent homology, the non-zero spectrum is likely of more interest to the practitioner. T

The matrix representation of the down Laplacian can be written as ( W K q ) − 1   B K q   W K q − 1 B K q . Following the same symmetrization procedure as above, its eigenvalues can be computed from the singular values of a matrix derived from B K q .

The boundary matrix B K q is sparse, with exactly ( q +1) non-zero entries per column corresponding to the faces of each q -simplex. Using the GKL algorithm we can approximate k eigenvalues of the down Laplacian in 2

$$
O \left ( k \times ( n _ { q } ^ { \mathcal { K } } \times ( q + 1 ) + n _ { q - 1 } ^ { \mathcal { K } } ) + k ^ { 2 } \right )
$$

arithmetic operations for a fixed complex K . The total time for all simplicial complexes in a full filtration from ∅ to L is bounded by

$$
O \left ( n _ { q } ^ { \mathcal { L } } \times \left ( k \times ( n _ { q } ^ { \mathcal { K } } \times ( q + 1 ) + n _ { q - 1 } ^ { \mathcal { K } } ) + k ^ { 2 } \right ) \right ) .
$$

This can potentially offer a significant improvement over methods requiring explicit matrix formation and dense eigensolvers, making the computation of a few eigenvalues a practical addition to persistent homology. We have included some computations in Fig. 11 for the k smallest eigenvalues and for the k largest eigenvalues. It is clear that this SVD-based approach is substantially more efficient than methods that first form the dense Laplacian matrix product.

Remark 5.3. An insightful method for visualizing topological evolution throughout a filtration involves plotting the barcode alongside a curve that tracks the smallest non-zero eigenvalue of the standard (non-persistent) Hodge Laplacian at each stage (see, e.g., [ WW23 , Figure 5]). Since the Hodge Laplacian is the sum of up and down Laplacians—whose top eigenvalues can be efficiently computed using the sparse matrix techniques as done for the complex K above—this visualization approach becomes practically generalizable to arbitrary (not necessarily non-branching) filtrations for large eigenvalues. This extension is a promising direction for future work.

# 6 Cubical complexes and X-Ray images

Cubical complexes provide an efficient framework for representing image data in TDA. In this section, we first present a simple example to demonstrate the computation of the persistent Laplacian in the context of cubical complexes (Example 6.1 ), then we experiment with this framework on an X-Ray image. From each of these four images, we derive two cubical complexes by thresholding pixel intensities. For each pair, we define a cube-wise filtration K j = K j 0   → K j 1   → ···   → K j m = L j , where each step K j i   → K j i +1 corresponds to the addition of a single 1-cube. # 7 Discussion and further work

The persistent Laplacian has already demonstrated superior performance compared to persistent homology on image data [ DWSG23 ]. We believe that the contributions of this paper makes the persistent Laplacian a practical tool for image data, e.g., by including the top k eigenvalues. Exploring the discriminatory power of such enhanced descriptors is a key direction for our future work (see also Remark 5.3 ). Another related and hitherto open problem is how to efficiently work with such a large number of eigenvalues in machine learning applications.

On the theoretical side, this paper introduces a Cheeger-type inequality for the persistent Laplacian. While the minimal non-zero eigenvalue, λ K , L min , of the up persistent Laplacian is known to capture geometric information, its stability under small perturbations of the filtration remains an important open question that warrants further investigation.

# A Graphs and incidence matrices

In this section, we describe the weighted graphs used in Section 2.4 .

Definition A.1. A directed (resp. undirected) graph G = ( V,E ) is a discrete structure where the vertex set V is a finite set and the edge set E is a set whose each element is an (resp. ordered) unordered pair of distinct vertices in V.

Definition A.2. We say G = ( V,E ) is an undirected graph with loops if each element e ∈ E is either an unordered pair of distinct vertices or a single vertex in V .

Definition A.3. The incidence matrix I ( G ) of an undirected graph (with loops) G = ( V,E ) is a { 0 , 1 } -matrix whose rows and columns are indexed by the vertices and edges of G respectively, such that the ( v,e )-entry of G is equal to 1 if v ∈ e , otherwise it is equal to 0.

Remark A.4. Usually the incidence matrix with respect to an undirected graph G with loops is a { 0 , 1 , 2 } -matrix, i.e., each loop is indexed by 2 in I ( G ), this is different from Definition A.3 .

We will then give the formal definition of the incidence matrix with respect to a directed graph G = ( V,E ). We refer to an ordered pair of adjacent vertices as an arc of G . An orientation of G is defined as a function σ from the arcs of G to {− 1 , 1 } such that if ( u,v ) is an arc, then σ ( u,v ) = − σ ( v,u ). We regard the edge [ uv ] as directed from tail u to head v if σ ( u,v ) = 1. A directed graph G is associated with a selected orientation σ .

Definition A.5. The incidence matrix I ( G ) of a directed graph G = ( V,E ) is the { 0 , ± 1 } -matrix with rows and columns indexed by vertices and edges of G respectively such that the ( u,e )-entry is equal to 1 if u is the head of e , − 1 if u is the tail of e , and 0 otherwise.

# E Golub-Kahan-Lanczos method

In this section we briefly review the Golub-Kahan-Lanczos method (GKL) to compute singular values of an m × n matrix A , mainly following the exposition in [ BDD + 00 , Section 6.3.3]. Let A ∈ M m × n ( R ), and without loss of generality we suppose that m ≥ n ; if m < n , we consider A T instead. We refer to the eigenvectors of the symmetric matrix A T A (resp. AA T ) as right singular vectors (resp. left singular vectors ). Our goal is to bidiagonalize the matrix A , i.e, to find a matrix factorization

$$
U ^ { T } \, A V = B = \left [ \begin{array} { c c c c } \alpha _ { 1 } & \beta _ { 1 } & & \\ & \alpha _ { 2 } & \beta _ { 2 } & \\ & & \ddots & \ddots \\ & & & \alpha _ { n - 1 } & \beta _ { n - 1 } \\ & & & & \alpha _ { n } \end{array} \right ] .
$$

Here V is an n × n orthogonal matrix and U is an n × m matrix orthogonal matrix whose column vectors are the left singular vectors associated with A , and all α ’s and β ’s are real. We denote by U =   u 1 u 2 ··· u n   , V =   v 1 v 2 ··· v n   , and observe that

$$
A \left [ v _ { 1 } \ \ v _ { 2 } \ \cdots \ \ v _ { n } \right ] & = \left [ u _ { 1 } \ \ u _ { 2 } \ \cdots \ \ u _ { n } \right ] B , \\ A ^ { T } \left [ u _ { 1 } \ \ u _ { 2 } \ \cdots \ \ u _ { n } \right ] & = \left [ v _ { 1 } \ \ v _ { 2 } \ \cdots \ \ v _ { n } \right ] B ^ { T } .
$$

Computing the j th column on both sides, we obtain that

$$
A v _ { j } & = \beta _ { j - 1 } u _ { j - 1 } + \alpha _ { j } u _ { j } , \\ A ^ { T } u _ { j } & = \alpha _ { j } v _ { j } + \beta _ { j } v _ { j + 1 } ,
$$

or equivalently, Proposition E.1. Let A ∈ M m × n ( R ) be a non-branching matrix. The GKL bidiagonalization of A costs O ( k ( m + n )) if iterating k times.

$$
\alpha _ { j } u _ { j } & = A v _ { j } - \beta _ { j - 1 } u _ { j - 1 } , \quad \beta _ { 0 } = 0 , \\ \beta _ { j } v _ { j + 1 } & = A ^ { T } u _ { j } - \alpha _ { j } v _ { j } .
$$

Since the columns of U and V are normalized, we also have

$$
\alpha _ { j } & = \| A v _ { j } - \beta _ { j - 1 } u _ { j - 1 } \| _ { 2 } , \\ \beta _ { j } & = \| A ^ { * } u _ { j } - \alpha _ { j } v _ { j } \| _ { 2 } .
$$

We can then compute the singular values of the bidiagonal matrix B by QR algorithm, according to [ BDD + 00 , Section 6.2]; it costs O ( n 2 ).

In practical applications, when the size of A is very large, it is usually not necessary to compute the entire bidiagonal matrix B , instead, we can iterate k steps to obtain a k × k bidiagonal matrix B k , whose singular values can be treated as an approximation to those of A . Typically, the algorithm will converge faster to larger singular values. We summarize the GKL algorithm in Algorithm 7 .
