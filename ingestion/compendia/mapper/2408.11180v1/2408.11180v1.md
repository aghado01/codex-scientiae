# ANY GRAPH IS A MAPPER GRAPH

ENRIQUE G ALVARADO, ROBIN BELTON, KANG-JU LEE, SOURABH PALANDE, SARAH PERCIVAL, EMILIE PURVINE, AND SARAH TYMOCHKO

Abstract. The Mapper algorithm is a popular tool for visualization and data exploration in topological data analysis. We investigate an inverse problem for the Mapper algorithm: Given a dataset X and a graph G , does there exist a set of Mapper parameters such that the output Mapper graph of X is isomorphic to G ? We provide constructions that affirmatively answer this question. Our results demonstrate that it is possible to engineer Mapper parameters to generate a desired graph.

# 1. Introduction

Topological data analysis (TDA) uses methods from topology to study the underlying structure and “shape” of a dataset. We refer the reader to [ 5 ] for an overview of this area. This paper focuses on Mapper , introduced in [ 22 ], a popular visualization tool in TDA that constructs a network representation of a dataset. Mapper has been used in many applications that include analyzing breast cancer data [ 17 ], identifying diabetes subgroups [ 14 ], and analyzing Passiflora leaves [ 20 ].

To apply the Mapper algorithm, the user needs to determine the following parameters: a lens (or filter ) function f : X → Y from X (the dataset, which we take to be a high-dimensional point cloud) to a lower-dimensional space Y , a cover of the image f ( X ) in Y , and a clustering algorithm for the preimage of each cover element. Mapper is known to be sensitive to its parameters, and many researchers have studied how to optimize them [ 26 , 7 , 4 , 2 , 18 , 19 ].

In this paper, we illustrate Mapper’s adaptability with respect to its parameters by providing constructions that show for a given dataset X and graph G , there exists a lens function f : X → Y with a reference space Y and a cover U of the image f ( X ) in Y , that, together with a particular clustering algorithm, generate a Mapper graph isomorphic to G .

# 2. Background

In this section, we collect the necessary terms related to Mapper graphs for the results of this work and recall the Mapper construction. We refer the reader to a standard text (e.g., [ 16 ]) for definitions and background in topology, and [ 6 , 15 ] for an overview of applied topology and topological combinatorics, respectively. Throughout this paper, the notation | σ | is used to denote the cardinality of a finite set σ .

2.1. Simplicial Complexes. We define simplicial complexes, which are often basic building blocks for extracting shapes from datasets.

Definition 2.1 (Simplicial Complex) . An (abstract) simplicial complex K is a collection of non-empty finite sets that is closed under the subset relation, i.e., if σ ∈ K and τ ⊆ σ , then τ ∈ K .

An element σ ∈ K is called a simplex and the dimension of σ is dim( σ ) : = | σ |− 1 . An i -dimensional simplex σ is called an i -simplex . In particular, 0 -simplices are vertices , denoted by V , and 1 -simplices are edges . The dimension of a simplicial complex K is the maximum of the dimensions of simplices in K . We call a 1 -dimensional simplicial complex a graph , which has no self-edges (also called loops) or multiple edges. It is referred to as a simple graph in the literature.

For a simplicial complex K , its geometric realization , denoted by ∥ K ∥ , is a geometric simplicial complex whose faces correspond to those of K . Note that the topology of ∥ K ∥ is a subspace topology of a Euclidean space and geometric realizations of K are homeomorphic to each other. Let e 0 denote the zero vector and e i denote the i th standard basis vector for i = 1 , 2 , ··· ,n − 1 . With a bijection ϕ : V → { 0 , 1 , ··· ,n − 1 } where n := | V | , the simplicial complex K can be realized in R n − 1 as ∥ K ∥ = { c ( σ ) | σ ∈ K } , where c ( σ ) is the convex hull of { e ϕ ( v ) } v ∈ σ .

2.2. Nerves and Nerve Theorems. The Mapper construction involves a special type of simplicial complex, called a nerve , which encodes the intersection patterns of a given collection of sets. Nerve theorems under some assumptions show the relationship between a topological space and the topology of the nerve complex for a cover of the space. This provides the foundation of the Mapper construction.

2.3. Mapper Construction. We now provide the Mapper construction for a given set of parameter choices. In 2007, Singh, Mémoli, and Carlsson introduced the construction, referring to it as the statistical version of Mapper [ 22 ]. It is also commonly known as the Mapper algorithm. For a dataset X , the Mapper construction produces a nerve with the following four steps: (See Figure 2 for an example of how to compute the Mapper graph for data points in R 2 .)

- (1) Select a lens (or filter ) function f : X → Y from X to a reference space Y ;
- (2) Choose a cover U of the image f ( X ) in Y , taken as an open or closed cover in practice [ 5 ];
- (3) Apply a clustering algorithm to f − 1 ( U ) for each U ∈ U and let f ∗ ( U ) be the collection of resulting clusters, i.e., f ∗ ( U ) : = { clusters of f − 1 ( U ) | U ∈ U} ;
- (4) Define the Mapper construction of X to be the nerve Nrv( f ∗ ( U )) of f ∗ ( U ) .

# 3. Any graph is a Mapper graph

In this section, we prove our main results showing that for a finite dataset X , any graph G is a Mapper graph with two different constructions. One construction employs a star cover of a graph and the other uses convex subsets of R 3 . In both cases, if X ⊆ R n , we show that the lens function can be taken to be a continuous function. As a clustering algorithm, we choose the trivial clustering algorithm , which simply returns { A } for any given set A ⊆ X . The Mapper construction with the trivial clustering algorithm can be formulated as follows.

Definition 3.1 (Mapper with trivial clustering) . Let f : X → Y be a function from a set X to a reference space Y . For any cover U of the image f ( X ) in Y and the cover f − 1 ( U ) : = { f − 1 ( U ) | U ∈ U} of X , we call the simplicial complex

$$

$$

the Mapper construction with trivial clustering .

3.1. Using the star cover of a graph G . We use the given graph G as the codomain for the lens function f with a star cover of G . The star of a vertex v , denoted by st( v ) , consists of the vertex v along with all edges containing v . The star cover is the collection of all stars of vertices of G . We equip the graph G with the Alexandrov topology , where the open sets are unions of stars [ 1 ]. With this topology, the star cover forms an open cover of G . We then select a lens function that maps at least one point of a dataset X to each edge or isolated vertex of G . The Mapper construction with these parameters leads to Theorem 3.2 . See Figure 3 for an example of how to construct the cover and lens function.

Theorem 3.2. Let X be a set of points. If G is a graph with vertex set V , edge set E , and isolated vertex set I such that | X | ≥ | E | + | I | , then there exists a cover U of G , and a function f : X → G such that the Mapper graph MT ( U ,f ) with trivial clustering is isomorphic to G .

Proof. Let U be the star cover of G defined as U : = { st( v ) | v ∈ V } . Since | X | ≥ | E | + | I | , we can define a function f : X → G such that f is surjective onto the edges and isolated vertices of G (i.e., each edge or isolated vertex has at least one point that is mapped onto it). Note that the vertex set of the Mapper graph with trivial clustering MT ( U ,f ) is given by f − 1 ( U ) . Consider a bijection φ : V → f − 1 ( U ) defined by φ ( v ) = f − 1 (st( v )) for each v ∈ V . Take v 1 ,v 2 ∈ V . By the definition of the nerve, { φ ( v 1 ) ,φ ( v 2 ) } is an edge of the Mapper graph if and only if f − 1 (st( v 1 )) ∩ f − 1 (st( v 2 )) is non-empty. Since f is surjective onto the edges and isolated vertices of G , we have f − 1 (st( v 1 )) ∩ f − 1 (st( v 2 )) ̸ = ∅ if and only if st( v 1 ) ∩ st( v 2 ) ̸ = ∅ . This occurs if and only if { v 1 ,v 2 } ∈ E . Therefore, { φ ( v 1 ) ,φ ( v 2 ) } is an edge of MT ( U ,f ) if and only if { v 1 ,v 2 } ∈ E , which shows that MT ( U ,f ) is isomorphic to G . □

Theorem 3.2 is admittedly quite contrived since using a graph G as the co-domain of the lens function is unlikely to be anyone’s first choice for a Mapper parameter. However, we are still able to construct a lens function and cover of R 3 such that any graph is a Mapper graph. Any graph can be realized in R d for d ≥ 3 , and the star of a vertex in G naturally corresponds to the star of the vertex in the realization. We modify the lens function in Theorem 3.2 so that it maps points to points in edges instead of edges themselves, and points for isolated vertices instead of isolated vertices themselves. This construction generates the Mapper graph isomorphic to G . The proof is analogous to that of Theorem 3.2 .

3.2. Using convex subsets of R 3 . Convex subsets of R 3 instead of star-shaped subsets would be an attractive choice for a cover in the Mapper construction. We provide a convex cover of R 3 and a lens function such that any graph can be represented as a Mapper graph. For this construction, we employ a result on d -representable complexes , which are simplicial complexes K that are isomorphic to the nerve of a finite collection of convex sets in R d . Wegner presented the representability and its optimality for graphs as 1 -dimensional simplicial complexes in 1967 [ 27 ] and Perel’man rediscovered this result in 1985 [ 21 ]. Refer to Section 4 for results concerning simplicial complexes.

Theorem 3.3 ([ 27 ]) . A graph G is 3 -representable, with 3 being the smallest possible value.

This collection will cover the image of a lens function with a co-domain in R 3 . The function maps our data points to the pairwise intersections between the convex sets, and to the convex sets corresponding to isolated vertices. Theorem 3.4 states that any graph is a Mapper graph with trivial clustering even using a cover to be made up of convex subsets of R 3 . This construction could potentially be implemented. 3.3. Inverse Problem with Continuous Lens Functions. While the lens function in Section 3.2 that maps points to intersections of convex sets is still somewhat contrived, we note that it can be formulated as a continuous function. We show that the lens function f : X → Y can be viewed as a continuous function and that f can be extended when X is a closed subset of R n , as in the case of finite point cloud datasets.

If the dataset X does not come from any natural underlying topological space, we can generate a topology on X using the preimages of the open sets in Y . If our dataset X is contained in a “nice” topological space, such as R n , we can extend f to a continuous function F on the whole space. This follows from the well-known Tietze extension theorem (see, for instance, [ 16 ]), which implies that any R d -valued continuous function on a closed subset of a normal topological space can be extended to a continuous function on the whole space.

Furthermore, when our dataset X is contained in R n , we have Lipschitz extensions and m -times continuously differentiable (denoted as C m ) extensions. Recall that a function g : Z → R d is Lipschitz continuous if there exists a real constant L ≥ 0 such that | f ( z 1 ) − f ( z 2 ) | ≤ L | z 1 − z 2 | for all z 1 ,z 2 ∈ Z , and the Lipschitz constant Lip( g ) of g is the smallest (infimum) of all such constants L .

If one does not care about increasing the Lipschitz constant Lip( f ) > 0 of f = ( f 1 ,...,f d ): X → R d by a constant factor, we have an explicit formula for its Lipschitz extension. The function F = ( F 1 ,...,F d ): R n → R d defined by

On the other hand, if we want to preserve the Lipschitz constant of f , Kirszbraun’s theorem states that an R d -valued Lipschitz function defined on an arbitrary subset of R n can be extended to a Lipschitz function on all of R n with the same Lipschitz constant (see [ 9 , 2.10.43] for an existence proof). Seeing how “nice” (i.e., small C m ( R n ) norm) the C m extension can be is an active area of research [ 10 , 11 ].

# 4. Generalizing Mapper Constructions to Simplicial Complexes

In this section, we will briefly see how our results from Section 3 generalize to general simplicial complexes. We will see how our constructions in Sections 3.1 , and 3.2 generalize to show that for any dataset X , any small enough simplicial complex K is a Mapper construction (Mapper simplicial complex). By “small enough” simplicial complex we mean that | X | ≥ | K \ V | + | I | , where V is the vertex set of K , K \ V is the set of all i -faces of K with i ≥ 1 , and I is the set of isolated vertices of K . This is analogous to the condition that | X | ≥ | E | + | I | where E is the edge set and I is the set of isolated vertices from Theorems 3.2 and 3.4 . We will also discuss how the continuous (e.g. Lipschitz continuous) extensions from Section 3.3 can be applied to the generalization of the results in Section 3.2 .

We begin by generalizing Theorem 3.2 to the case of simplicial complexes K endowed with the Alexandrov topology. We consider the (simplicial) star open cover of K along with a lens function f : X → K that maps at least one point X to each isolated vertex, and each i -face of K for i ≥ 1 instead of each edge of a graph.

Theorem 4.1. Let X be a set of points. If K is a simplicial complex with vertex set V and isolated vertex set I such that | X | ≥ | K \ V | + | I | , then there exists a cover U of K , and a function f : X → K such that the Mapper construction with trivial clustering MT ( U ,f ) is isomorphic to K .

Since any simplicial complex of dimension d can be realized in R 2 d +1 where 2 d +1 is as small as possible (by the van Kampen-Flores theorem) [ 25 , 12 ], we have a star cover in R 2 d +1 along with a lens function that maps at least one point to each intersection of stars and points for isolated vertices. Similarly, Theorem 3.4 also holds in R 2 d +1 due to the generality of Theorem 3.3 on d -representable complexes [ 27 , 23 ], using a lens function that maps at least one point to intersections of convex sets and convex sets for isolated vertices.

Theorem 4.2. Let X be a set of points. If K is a simplicial complex with vertex set V and isolated vertex set I such that | X | ≥ | K \ V | + | I | , then there exists a collection C of convex sets in R 2 d +1 and a function f : X → R 2 d +1 such that the Mapper construction MT ( C ,f ) with trivial clustering is isomorphic to K .

Finally, we note that the Lipschitz extension used in Proposition 3.5 is general enough to apply to the function f : X → R 2 d +1 constructed in Theorem 4.2 as follows.

# 5. Conclusion

In this paper, we showed that, given any point cloud and any simplicial complex, there exist parameters such that the Mapper construction of the input point cloud results in the given simplicial complex under a mild condition. Additionally, this result can still be achieved when limiting the Mapper algorithm to parameters that arise more naturally in practice, such as requiring the lens function to be a C n or Lipschitz continuous function, and requiring the open cover to consist of convex sets. Given this flexibility of the Mapper algorithm, we encourage users to carefully consider the effects of parameter choices on the resulting Mapper construction.
