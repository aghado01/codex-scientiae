This result has a nice interpretation, as follows. After observing N − 1 data points we have estimated µ by µ ( N − 1) ML . We now observe data point x N , and we obtain our revised estimate µ ( N ) ML by moving the old estimate a small amount, proportional to 1 /N , in the direction of the ‘error signal’ ( x N − µ ( N − 1) ML ) . Note that, as N increases, so the contribution from successive data points gets smaller.
