Proof of Lemma 1

If ˜ X = ˜ WR with R ∈ O ( r ), then

For the uncentered equivalence, note that H 1 n = 0 , so for any t ∈ R r ,

$$

$$

Thus X = WR + 1 n t ⊤ implies Φ( X ) = Φ( W ). Conversely, if Φ( X ) = Φ( W ) then HX = HWR for some R ∈ O ( r ) by the first part, and therefore X − WR must be a pure translation, i.e., X = WR + 1 n t ⊤ for some t ∈ R r .

## Proof of Theorem 2

Let g = ( R , t ) ∈ O ( r ) × R r act on latent configurations by

$$
g \cdot X \colon = X R + 1_{n} t^{\top} .
$$

By construction of the centered Gram map,

$$
\Phi ( g \cdot X ) = H ( X R + 1_{n} t^{\top} ) ( X R + 1_{n} t^{\top} )^{\top} H .
$$

Since H 1 n = 0 , all terms involving t vanish after centering, and we obtain

$$
\Phi ( g \cdot X ) = H X R R^{\top} X^{\top} H = H X X^{\top} H = \Phi ( X ) .
$$

Therefore, the map Φ is invariant under rigid motions. It follows that the induced posterior law of B = Φ( X ) is unchanged if one replaces X by g · X . Hence any measurable functional of Π B ( · | A ) is invariant under rigid motions of the latent coordinates.

The summaries listed in the statement are all measurable functionals of Π B ( · | A ) by their definitions. Therefore they are canonical.

## Proof of Theorem 3

Let

$$
F ( B ) \coloneqq \int d^{2} ( B , B^{\prime} ) \, \Pi_{B} ( d B^{\prime} \, | \, A ) , \quad B \in \mathcal{M}_{n , r} ,
$$

denote the posterior Fréchet functional. By assumption, F ( B 0 ) < ∞ for some B 0 ∈ M n,r . Let { B n } n ≥ 1 ⊂ M n,r be a minimizing sequence, so that

$$
F ( B_{n} ) \downarrow \inf_{B \in \mathcal{M}_{n , r}} F ( B ) .
$$

Since F ( B n ) ≤ F ( B 0 ) + 1 for all sufficiently large n , it suffices to work with such n .

We first show that { B n } is bounded in the metric d . For any fixed B ′ ∈ M n,r , the triangle inequality gives

$$
d ( B_{n} , B_{0} ) \leq d ( B_{n} , B^{\prime} ) + d ( B^{\prime} , B_{0} ) .
$$

Integrating with respect to Π B ( d B ′ | A ) and applying Jensen’s inequality to each term yields

$$
d ( B_{n} , B_{0} ) \leq \int d ( B_{n} , B^{\prime} ) \, \Pi_{B} ( d B^{\prime} \ | \ A ) + \int d ( B^{\prime} , B_{0} ) \, \Pi_{B} ( d B^{\prime} \ | \ A ) \leq \sqrt{F ( B_{n} )} + \sqrt{F ( B_{0} )} .
$$

Hence, for all sufficiently large n ,

$$
d ( B_{n} , B_{0} ) \leq \sqrt{F ( B_{0} ) + 1} + \sqrt{F ( B_{0} )} ,
$$

so the sequence is bounded in d .

Next, choose centered factors B n = Y n Y ⊤ n and B 0 = Y 0 Y ⊤ 0 with Y ⊤ n 1 n = Y ⊤ 0 1 n = 0 . By definition of the quotient distance, for each n there exists R n ∈ O ( r ) such that

.

$$
\| Y_{n} - Y_{0} R_{n} \|_{F} \leq d ( B_{n} , B_{0} ) + \frac{1}{n} .
$$

Therefore,

$$
\| Y_{n} \|_{F} \leq \| Y_{n} - Y_{0} R_{n} \|_{F} + \| Y_{0} R_{n} \|_{F} \leq d ( B_{n} , B_{0} ) + \frac{1}{n} + \| Y_{0} \|_{F} .
$$

Since { B n } is bounded in d , the sequence { Y n } is bounded in the finite-dimensional Euclidean space { Y ∈ R n × r : Y ⊤ 1 n = 0 } . Hence, by the Bolzano–Weierstrass theorem, there exists a subsequence { Y n k } and a limit Y such that

$$
Y_{n_{k}} \rightarrow Y \quad \text{in Frobenius norm.}
$$

Because the centering constraint is closed, Y ⊤ 1 n = 0 . Define

$$
B_{F} \colon = Y Y^{\top} \in \mathcal{M}_{n , r} .
$$

Then, by taking the competitor R = I r ,

$$
d ( B_{n_{k}} , B_{F} ) \leq \| Y_{n_{k}} - Y \|_{F} \to 0 .
$$

It remains to show that B F minimizes F . Since sup k d ( B n k , B 0 ) < ∞ , there exists a constant C < ∞ such that

$$
d ( B_{n_{k}} , B^{\prime} ) \leq d ( B_{n_{k}} , B_{0} ) + d ( B_{0} , B^{\prime} ) \leq C + d ( B_{0} , B^{\prime} )
$$

for all k and all B ′ . Therefore,

$$
d^{2} ( B_{n_{k}} , B^{\prime} ) \leq 2 C^{2} + 2 d^{2} ( B_{0} , B^{\prime} ) ,
$$

and the right-hand side is integrable under Π B ( · | A ) by the finite second-moment assumption. Since d ( B n k , B ′ ) → d ( B F , B ′ ) pointwise in B ′ , dominated convergence gives

$$
F ( B_{n_{k}} ) \rightarrow F ( B_{F} ) .
$$

Because { B n k } is a minimizing subsequence, it follows that

$$
F ( B_{F} ) = \inf_{B \in \mathcal{M}_{n , r}} F ( B ) .
$$

Thus B F is a Fr´echet mean of Π B ( · | A ).

## Proof of Theorem 4

Let γ be an optimal coupling of P and Q , so that

$$
\int d^{2} ( B_{1} , B_{2} ) \, \gamma ( d B_{1} , d B_{2} ) = W_{2}^{2} ( P , Q ) = w^{2} .

Fix any B ∈ M n,r . Using the identity | a 2 − b 2 | = | a − b | ( a + b ) and the triangle inequality, we obtain

$$
\begin{aligned}
| d^{2} ( B , B_{1} ) - d^{2} ( B , B_{2} ) | & = | d ( B , B_{1} ) - d ( B , B_{2} ) | \left ( d ( B , B_{1} ) + d ( B , B_{2} ) \right ) \\ & \leq d ( B_{1} , B_{2} ) \left ( d ( B , B_{1} ) + d ( B , B_{2} ) \right ) .
\end{aligned}
$$

Integrating with respect to γ and applying Cauchy–Schwarz gives

$$
\begin{aligned}

\end{aligned}
$$

Thus, for every B ∈ M n,r ,

$$
| F_{P} ( B ) - F_{Q} ( B ) | \leq w \, \sqrt{2 F_{P} ( B ) + 2 F_{Q} ( B )} .
$$

Now let By the quadratic growth condition,

$$
\delta \coloneqq d ( \mu_{P} , \mu_{Q} ) , \quad M \coloneqq \sqrt{F_{P} ( \mu_{P} )} + \sqrt{F_{Q} ( \mu_{Q} )} .

$$
\frac{\lambda}{2} \delta^{2} \leq F_{P} ( \mu_{Q} ) - F_{P} ( \mu_{P} ) .
$$

Since µ Q minimizes F Q , we have F Q ( µ Q ) ≤ F Q ( µ P ), and therefore

$$
F_{P} ( \mu_{Q} ) - F_{P} ( \mu_{P} ) \leq | F_{P} ( \mu_{Q} ) - F_{Q} ( \mu_{Q} ) | + | F_{P} ( \mu_{P} ) - F_{Q} ( \mu_{P} ) | .

Applying (17) at B = µ Q and B = µ P yields

$$
\frac{\lambda}{2} \delta^{2} \leq w \sqrt{2 F_{P} ( \mu_{Q} ) + 2 F_{Q} ( \mu_{Q} )} + w \sqrt{2 F_{P} ( \mu_{P} ) + 2 F_{Q} ( \mu_{P} )} .
$$

We next bound the two square-root terms. By the triangle inequality,

$$
d ( \mu_{Q} , B ) \leq d ( \mu_{P} , B ) + \delta \quad \text{for all $B\in \mathcal{M}_{n,r}$} .
$$

Applying Minkowski’s inequality under P gives

$$
\sqrt{F_{P} ( \mu_{Q} )} = \left ( \int d^{2} ( \mu_{Q} , B ) \, P ( d B ) \right )^{1 / 2} \leq \left ( \int d^{2} ( \mu_{P} , B ) \, P ( d B ) \right )^{1 / 2} + \delta = \sqrt{F_{P} ( \mu_{P} )} + \delta .
$$

Similarly,

$$
\sqrt{F_{Q} ( \mu_{P} )} \leq \sqrt{F_{Q} ( \mu_{Q} )} + \delta .
$$

Therefore,

$$
\begin{aligned}
& \sqrt{2 F_{P} ( \mu_{Q} ) + 2 F_{Q} ( \mu_{Q} )} \leq \sqrt{2} ( \sqrt{F_{P} ( \mu_{Q} )} + \sqrt{F_{Q} ( \mu_{Q} )} ) \leq \sqrt{2} ( M + \delta ) , \\ & \sqrt{2 F_{P} ( \mu_{P} ) + 2 F_{Q} ( \mu_{P} )} \leq \sqrt{2} ( \sqrt{F_{P} ( \mu_{P} )} + \sqrt{F_{Q} ( \mu_{P} )} ) \leq \sqrt{2} ( M + \delta ) .
\end{aligned}
$$

Substituting these bounds into (19) gives

$$
\frac{\lambda}{2} \delta^{2} \leq 2 \sqrt{2} \, w ( M + \delta ) .

Rearranging,

$$
\delta^{2} - a \delta - a M \leq 0 , \quad a \colon = \frac{4 \sqrt{2}}{\lambda} w .

Since δ ≥ 0, this implies

\delta \leq \frac{a + \sqrt{a^{2} + 4 a M}}{2} .
$$

Using √ a 2 + 4 aM ≤ a + 2 √ aM for a,M ≥ 0, we obtain

$$
\delta \leq a + \sqrt{a M} .
$$

Substituting the definition of a and M yields

$$
d ( \mu_{P} , \mu_{Q} ) \leq \frac{4 \sqrt{2}}{\lambda} \, w + 2^{5 / 4} \sqrt{\frac{w}{\lambda}} \left ( \sqrt{F_{P} ( \mu_{P} )} + \sqrt{F_{Q} ( \mu_{Q} )} \right )^{1 / 2} .

This proves the stated bound. The final claim follows immediately, since the right-hand side tends to zero as w = W 2 ( P,Q ) → 0.

## Proof of Theorem 5

Let

$$
F ( B ) \colon = \int d^{2} ( B , B^{\prime} ) \, \Pi_{B} ( d B^{\prime} \ | \ A )
$$

denote the population Fréchet functional associated with the induced posterior, and let B F be any Fréchet mean of Π B ( · | A ). By the minimizing property of B F ,

$$
F ( B_{F} ) \leq F ( B^{*} ) = \int d^{2} ( B^{*} , B ) \, \Pi_{B} ( d B \, | \, A ) .
$$

By the posterior mean-square concentration assumption in the manuscript, the right-hand side converges to zero in probability. Hence

$$
F ( B_{F} ) \stackrel{P}{\rightarrow} 0 .
$$

To control d ( B F , B ⋆ ), fix B and apply the triangle inequality:

$$
d ( B_{F} , B^{*} ) \leq d ( B_{F} , B ) + d ( B , B^{*} ) .
$$

Squaring both sides and using ( a + b ) 2 ≤ 2 a 2 + 2 b 2 yields

$$
d^{2} ( B_{F} , B^{*} ) \leq 2 d^{2} ( B_{F} , B ) + 2 d^{2} ( B , B^{*} ) .
$$

Integrating with respect to Π B ( d B | A ) gives

$$
d^{2} ( B_{F} , B^{*} ) \leq 2 F ( B_{F} ) + 2 F ( B^{*} ) \leq 4 F ( B^{*} ) .
$$

Since F ( B ⋆ ) P −→ 0, it follows that

$$
d ( B_{F} , B^{*} ) \stackrel{P}{\rightarrow} 0 .
$$

It remains to transfer this to pairwise distances. Choose centered factors

$$
B_{F} = Y_{F} Y_{F}^{\top} , \quad B^{*} = Y^{*} Y^{*^{\top}} ,
$$

with

$$
Y_{F}^{\top} 1_{n} = ( Y^{*} )^{\top} 1_{n} = 0 ,
$$

and align them so that

$$
\| Y_{F} - Y^{*} \|_{F} = d ( B_{F} , B^{*} ) .
$$

Let y F,i and y ⋆ i denote their i th rows. Then

$$
\begin{aligned}
| D_{i j} ( B_{F} ) - D_{i j} ( B^{*} ) | & = \left \| | y_{F , i} - y_{F , j} | - \| y_{i}^{*} - y_{j}^{*} \| \right \| \\ & \leq \| ( y_{F , i} - y_{F , j} ) - ( y_{i}^{*} - y_{j}^{*} ) \| \\ & \leq \| y_{F , i} - y_{i}^{*} \| + \| y_{F , j} - y_{j}^{*} \| \\ & \leq 2 | | Y_{F} - Y^{*} | |_{F} \\ & = 2 d ( B_{F} , B^{*} ) .
\end{aligned}
$$

Since d ( B F , B ⋆ ) P −→ 0, we conclude that

$$
D_{i j} ( B_{F} ) \stackrel{P}{\rightarrow} D_{i j} ( B^{*} ) .
$$

## Proof of Corollary 6

By Theorem 5 and the assumption on ¯ α , we have

## Proof of Theorem 7

Fix a node i and another node j ̸ = i . Let B denote a random matrix drawn from Π B ( · | A ). Since D ij ( B ⋆ ) is a constant,


$$
\text{Var} \{D_{i j} ( B ) \} \leq E \left [ \left ( D_{i j} ( B ) - D_{i j} ( B^{*} ) \right )^{2} | \ A \right ] .
$$

As in the proof of Theorem 5, the pairwise distance functional is Lipschitz with respect to the quotient distance:

$$
| D_{i j} ( B ) - D_{i j} ( B^{*} ) | \leq 2 d ( B , B^{*} ) .
$$

Therefore,

$$
\text{Var} \{D_{i j} ( B ) \} \leq 4 E \left [ d^{2} ( B , B^{*} ) \, | \, A \right ] = 4 \, \int d^{2} ( B , B^{*} ) \, \Pi_{B} ( d B \, | \, A ) .
$$

By the posterior mean-square concentration assumption in the manuscript, the right-hand side converges to zero in probability. Hence

$$
V a r \{D_{i j} ( B ) \} \stackrel{P}{\rightarrow} 0 \quad \text{for every} j \neq i .
$$


Finally, recalling the definition

$$
U_{i} = \frac{1}{n - 1} \sum_{j \neq i} \text{Var} \{D_{i j} ( B ) \} ,
$$


and noting that the number of terms in the sum is finite, we conclude that

$$
U_{i} \stackrel{P}{\rightarrow} 0 .
$$

## Derivation of the Classical MDS Identity

A brief derivation is as follows. Write ˜ X = HX , so B = ˜ X ˜ X ⊤ . For any i,j ∈ [ n ] × [ n ],

$$
\Delta_{i j} = \| \tilde{x}_{i} - \tilde{x}_{j} \|^{2} = \tilde{x}_{i}^{\top} \tilde{x}_{i} + \tilde{x}_{j}^{\top} \tilde{x}_{j} - 2 \tilde{x}_{i}^{\top} \tilde{x}_{j} .
$$

In matrix form,

$$
\Delta = d i a g ( B ) 1_{n}^{\top} + 1_{n} d i a g ( B )^{\top} - 2 B .
$$

Premultiplying and postmultiplying by H removes the two terms involving 1 n , yielding

$$
H \Delta H = - 2 H B H = - 2 B ,
$$

because HB = B and BH = B .

## Coauthorship Preprocessing Details

The coauthorship analysis begins from the MATLAB file CoauAdjFinal.mat , which stores an adjacency matrix A together with the corresponding author names. This file is produced from the author–paper incidence data in the MADStat repository available at https://github.com/ZhengTracyKe/MADStat by first forming the weighted coauthorship matrix A wt = XX ⊤ , where X is the author–paper incidence matrix, then thresholding the weights so that

A ij = 1 ⇐⇒ authors i and j coauthored at least three papers ,

and setting A ii = 0. The resulting thresholded graph is then restricted to its largest connected component before being saved in CoauAdjFinal.mat . In our case, this network contains 4,383 authors.

Community labels are taken from the companion file CommunityResults firstlayer.mat , which stores the first-layer partition used in Ji et al. (2022). These labels are obtained by applying SCORE to the adjacency matrix with diagonal regularization and then relabeling the six detected communities to match the interpretation in that paper. In the R implementation, the author ordering in CoauAdjFinal.mat and CommunityResults firstlayer.mat was checked using the stored authorNames fields, and all subsequent preprocessing was carried out only after verifying that the node orderings agreed.

We then restricted attention to the three first-layer biostatistics communities with labels 2, 4, and 6, corresponding to Biostatistics (Europe), Biostatistics (UNC), and Biostatistics (Michigan), respectively. Their sizes are 202, 673, and 264, yielding an induced subgraph on 1,139 authors. This induced subgraph is disconnected: it contains 64 connected components, of which the largest has 980 nodes. All subsequent model fitting and posterior analysis are based on this 980-node component.

For computational feasibility, the final fitted network was obtained by trimming the 980node component to a connected 400-node subgraph. In the analysis code, nodes were ranked by degree within the 980-node component, the highest-degree 400 nodes were retained, and the largest connected component of this retained subgraph was used for model fitting. The latent space model and all quotient-based summaries reported in the main text are therefore based on this final connected 400-node network.
