## Appendix A Validity of permutation p -values

For a sequence of exchangeable random variables X 1 ,...,X n +1 , Lemma 1 of Romano and Wolf ( 2005 ) shows that

$$
P \left ( \frac{1}{n + 1} \left \{\sum_{i = 1}^{n} I ( X_{n + 1} \leq X_{i} ) + 1 \right \} \leq \alpha \right ) \leq \alpha , \quad \text{for all} \alpha \in [ 0 , 1 ] .
$$

In this section, we provide a slightly sharper result than Lemma 1 of Romano and Wolf ( 2005 ). In fact, Romano and Wolf ( 2005 ) state their result without proof, which encourages us to present a full proof for completeness.

Lemma A.1 Suppose that X 1 ,...,X n ,X n +1 are exchangeable random variables. Then for any α ∈ [0 , 1] , it holds that

$$
P \left ( \frac{1}{n + 1} \left \{\sum_{i = 1}^{n} I ( X_{n + 1} \leq X_{i} ) + 1 \right \} \leq \alpha \right ) \leq \frac{\lfloor ( n + 1 ) \alpha \rfloor}{n + 1} \leq \alpha ,
$$

where x is the largest integer smaller than or equal to x . Suppose further that X 1 ,...,X n +1 are all distinct with probability one. Then

$$
P \left ( \frac{1}{n + 1} \left \{\sum_{i = 1}^{n} I ( X_{n + 1} \leq X_{i} ) + 1 \right \} \leq \alpha \right ) = \frac{\lfloor ( n + 1 ) \alpha \rfloor}{n + 1} .
$$

Proof Let X (1) ≤ X (2) ≤ ... ≤ X ( n +1) be the order statistics of X 1 ,...,X n +1 . Then we

$$
\begin{aligned}
\text{observe that} \\ \frac{1}{n + 1} \left \{\sum_{i = 1}^{n} I ( X_{n + 1} \leq X_{i} ) + 1 \right \} & = \frac{1}{n + 1} \sum_{i = 1}^{n + 1} I ( X_{n + 1} \leq X_{i} ) \leq \alpha \\ \iff \sum_{i = 1}^{n + 1} I ( X_{n + 1} \leq X_{i} ) \leq \lfloor ( n + 1 ) \alpha \rfloor \\ \iff \sum_{i = 1}^{n + 1} I ( X_{i} < X_{n + 1} ) \geq ( n + 1 ) - \lfloor ( n + 1 ) \alpha \rfloor \coloneqq k \\ \iff X_{n + 1} > X_{( k )} . \\
\end{aligned}
$$

Now by the exchangeability condition, we have

$$
P ( X_{n + 1} > X_{( k )} ) \, = \, E \left [ \frac{1}{n + 1} \sum_{i = 1}^{n + 1} I ( X_{i} > X_{( k )} ) \right ] .
$$

On the other hand, by the definition of X ( k ) ,

$$
\frac{1}{n + 1} \sum_{i = 1}^{n + 1} I ( X_{i} > X_{( k )} ) \leq \frac{n + 1 - k}{n + 1} = \frac{\lfloor ( n + 1 ) \alpha \rfloor}{n + 1} .
$$

Hence the first result follows. When X 1 ,...,X n +1 are all distinct, observe

$$
\sum_{i = 1}^{n + 1} I ( X_{i} > X_{( k )} ) = n + 1 - k .
$$

Thus the second result follows as

$$
E \left [ \frac{1}{n + 1} \sum_{i = 1}^{n + 1} I ( X_{i} > X_{( k )} ) \right ] = \frac{n + 1 - k}{n + 1} = \frac{\lfloor ( n + 1 ) \alpha \rfloor}{n + 1} .
$$
