# Document Repair Checklist

## 1. Heading Hygiene
- Keep a single `#` title at the top of the file.
- All top‑level sections must be `##`.
- Subsections follow a logical hierarchy (`###`, `####`, …).
- No skipped heading levels.

## 2. Table of Contents (TOC)
- Place a linked TOC immediately after the title.
- Use markdown links with anchors, e.g. `[Introduction](#introduction)`.
- Include every top‑level heading and its immediate subsections.

## 3. Math Clean‑up
- Wrap stray variables in `$…$` (inline) or `$$…$$` (block).
- Re‑construct fragmented piecewise blocks into `$$\begin{cases} … \end{cases}$$`.
- Replace OCR‑generated ligatures (`ﬂ`, `ﬁ`, `ﬀ`) with their ASCII equivalents.

## 4. Duplicate Text Removal
- Detect and delete duplicated prose often caused by `\intertext{}` followed by the same plain paragraph.
- Ensure only one copy of each sentence remains.

## 5. Figures & Captions
- Every image (`![alt](path)`) must have a caption paragraph directly beneath it.
- Captions should be concise and start with **Figure X:**.

## 6. OCR Glyph & Symbol Cleanup
- Map common OCR glyphs (`inf`, `sup`, ``, etc.) back to proper LaTeX commands.
- Verify that superscripts/subscripts are attached to the correct base expression.

## 7. Final Lint Pass
- Run a markdown linter to catch broken links, missing alt‑text, and heading level skips.
- Validate that all internal links (including TOC) resolve correctly.
